S - Principio de Responsabilidad Única (Single Responsibility)

Este principio dice que una clase debe tener una sola responsabilidad, es decir, una única razón para cambiar. Si una clase se encarga de varias tareas a la vez, un cambio en una de ellas puede romper las demás.

Por ejemplo, una clase que calcula el salario de un empleado no debería también guardarlo en la base de datos ni imprimir su recibo. Cada una de esas tareas debe estar en su propia clase.
