O - Principio Abierto/Cerrado (Open/Closed)

Este principio establece que el código debe estar abierto para extenderse, pero cerrado para modificarse. Esto significa que se pueden agregar nuevas funcionalidades sin cambiar el código que ya funciona.

Por ejemplo, si un sistema calcula descuentos y mañana se necesita un descuento nuevo, lo ideal es crear una clase nueva para ese descuento en lugar de editar la clase existente y arriesgarse a introducir errores.
